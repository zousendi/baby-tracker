# こもれび — baby-tracker

赤ちゃんの授乳・おしっこ・うんちを記録する、日本語のレスポンシブWebアプリのデモ。

## 起動

Node.js 22以降で `npm run dev` を実行し、http://localhost:5173 を開きます。PowerShellでnpmの実行制限が出る場合は `npm.cmd run dev` を使用してください。

## できること

- ミルク・搾母乳の時刻とmlを入力。量のプリセット、±10ml、現在時刻ボタン。
- 母乳（直母）の左右の分数、おしっこ、うんち、両方のおむつを記録。
- 記録の編集・削除・削除直後の取り消し、日付切り替え、種類で絞り込み。
- 日別合計・前日の同時刻との比較・その日の平均授乳間隔・7日間のグラフ。
- 任意のミルク量の目安との比較、見守りガイド。
- ブラウザ内保存、JSON書き出し。デモと実際の記録は別データ。

初回は架空のサンプルを表示します。「自分の記録をはじめる」で空の記録に切り替わります。端末間の同期、アカウント、通知、バックアップの取り込みは未実装です。ブラウザの保存データを消すと記録も消えます。

## iPhone

Safariの画面幅とタッチ操作に対応しています。同じWi-Fiに接続したiPhoneから `http://PCのIPv4アドレス:5173` を開けばローカル確認できます（PCでサーバー起動中、Windowsファイアウォールが許可している場合）。インターネットから使うには、Sitesなどでの公開URLが必要です。

## Sitesへ引き継ぐ

このセッションにはSitesの作成・保存・公開ツールが提供されていないため、Sitesへの登録・公開は未実施です。

公式案内: https://learn.chatgpt.com/docs/sites

Sitesが使えるChatGPTのWebまたはデスクトップで、このプロジェクトを指定して次のように依頼できます。

> @Sites このbaby-trackerプロジェクトから授乳記録デモ「こもれび」を作成してください。npm run build の出力distが静的サイトです。iPhoneで検証し、まずバージョンを保存してください。記録は各訪問者のブラウザ内だけに保存し、サーバーに送信しない設計を維持してください。

`npm run build` は `dist/` に静的ファイルを出力します。ランタイムのライブラリ・APIキー・バックエンドは不要です。Google Fontsを使っていますが、取得できない場合は端末のフォントにフォールバックします。

## 見守り表示

医療的な過不足の診断は行いません。目安は利用者が医師・助産師と相談した数値を設定するもので、デモの700〜900mlは操作説明用の例です。直母の分数はmlに換算せず、当日の途中経過を「不足」と判定しません。記録がない日は0表示です。

参考: NHS「Breastfeeding: is my baby getting enough milk?」および「Bottle feeding your baby」。アプリの見守りガイドから参照できます。

## 検証

- `npm test`: 日付境界・授乳集計・目安表示・入力検証・サンプルデータのテスト。
- `npm ci` で検証用依存関係をインストールできます（アプリの起動には不要）。
- `npm run test:browser`: 開発サーバー起動中にPlaywrightで実行。Microsoft Edgeが必要です。
- Safari系WebKit検証: `npx playwright install webkit` 後、PowerShellで `$env:TEST_BROWSER = 'webkit'` を設定して `npm run test:browser`。iPhone相当のタッチ・モバイル設定でも操作を検証します。実機iPhoneでの検証とは異なります。
- `npm run build`: 静的サイト出力。

開発用サーバーは公開ファイルのみを配信し、`.git`・`.env`・`.venv`などは配信しません。
