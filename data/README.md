# ゆうさくくんの記録データ

`yusaku-records.json` は、ユーザーの依頼でGitに保存した家庭の記録スナップショットです。日時はUTCのISO形式で、日本時間に変換して表示します。

WORKの公開先では、既存の「ゆうさくくん」家庭のIDを使用して取り込んでください。49件の記録が含まれます。ログイン情報・セッション・管理キーは含みません。

各記録の `id` を保持し、既存IDがある場合は追加しないことで再取り込みの重複を防げます。公開先の `created_by` / `updated_by` は、その家庭の取り込み担当アカウントIDを設定してください。`version` は新規登録時1とします。家庭名だけで別家庭への書き込みを行わず、対象家庭を確認してください。

このファイルは出力時点のデータです。公開後の記録はクラウドDBに保存され、Gitへ自動同期されません。
